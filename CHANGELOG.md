# Changelog

Versions stay `v0.x` until the API settles: the minor version marks changes
that may break callers, the patch version marks fixes.

## v0.1.0

- First release: FreeType 2 through FFI over the system `libfreetype` (2.10
  or newer), for rasterizing text in games.
- `freetype.library`: `Library` (`FT_Init_FreeType`) as a resource, with
  `open_face(fs, path)` and `face_from_bytes(bytes)`; a memory face keeps
  its own copy of the bytes.
- `freetype.face`: `Face` (`FT_Done_Face`) with `set_pixel_size`,
  `char_index`, `glyph` (rendered to 8-bit grayscale `Glyph`s), `kerning`,
  `has_kerning`, `metrics`, `family_name`, and `style_name`. Faces keep
  their library alive: `FT_Done_FreeType` runs after the library and its
  last face have closed. Neither resource is `send` (FreeType's threading
  rules; see the README).
- `freetype.error`: `FreeTypeError` with a kind from `FT_Error`, the code,
  and `FT_Error_String`.
- Bindings: `src/sys/` generated by `anvil ffi gen`, pinned to the
  declarations the package uses; `FT_New_Memory_Face` hand-written with a
  `Ptr[u8]` buffer.
- `examples/text` renders a line of text into a PNG.
- Requires `ferron >=0.9.0-alpha.1`; CI pins `FERRON_REF: v0.9.0-alpha.1`
  and checks `live_handles=0` after `anvil test`.
